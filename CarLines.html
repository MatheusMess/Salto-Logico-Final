Fase 1: Alinhamento Básico Iniciante

Ajude o motorista a estacionar o carro vermelho no lado direito do pátio usando a propriedade justify-content.

💡 Dica útil:

Experimente usar justify-content: flex-end; para alinhar itens ao final do eixo principal.

parking-style.css
#patio-estacionamento {
1 2 3 4 5
display: flex;
}
Alinhando veículos...
justify-content:

Define o alinhamento no eixo principal (geralmente horizontal):

  • flex-start: Alinha ao início (padrão).
  • flex-end: Alinha ao final.
  • center: Centraliza os itens.
  • space-between: Distribui com espaçamento igual entre eles.
  • space-around: Distribui com espaçamento igual ao redor de cada.
  • space-evenly: Espaço igual entre todos, incluindo as bordas.
align-items:

Define o alinhamento no eixo transversal (vertical):

  • flex-start: Topo.
  • flex-end: Base.
  • center: Alinhamento centralizado verticalmente.
  • baseline: Alinha pela linha de base do texto.
  • stretch: Estica para preencher o container (padrão).
flex-direction:

Altera a direção dos itens no container:

  • row: Linha horizontal (padrão).
  • row-reverse: Linha horizontal invertida.
  • column: Coluna vertical.
  • column-reverse: Coluna vertical invertida.
flex-wrap:

Define se os itens quebram de linha:

  • nowrap: Mantém tudo em uma única linha.
  • wrap: Quebra para novas linhas se faltar espaço.
  • wrap-reverse: Quebra para novas linhas em ordem reversa.
align-content:

Controla o espaçamento entre as fileiras de linhas no eixo transversal (apenas funciona se houver `flex-wrap` e múltiplas linhas):

  • flex-start: Linhas compactadas no topo.
  • flex-end: Linhas compactadas na base.
  • center: Linhas compactadas no centro.
  • space-between: Fileiras de linhas distribuídas nas extremidades.
  • space-around: Fileiras de linhas distribuídas uniformemente com margens.
